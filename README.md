# Mahmoud Fathy — المكتبة الدعوية

موقع عربي RTL ثابت (HTML/CSS/JS) مبدئي، دون build step.

## المزايا
- تصميم متجاوب للموبايل والحاسوب.
- رابطا منشوري Telegram كبداية: /452 و /449.
- تضمين منشورات Telegram العامة عبر `?embed=1`.
- دعم YouTube عبر iframe رسمي.
- دعم روابط ملفات الصوت والفيديو المباشرة.
- بحث وتصنيفات ولوحة إدارة تجريبية.

## نشر مجاني
اربط المستودع بـ Cloudflare Pages أو استخدم أي استضافة static مجانية. لا توجد أوامر build؛ مجلد الإخراج هو جذر المستودع.

## تنبيه
لوحة الإدارة الحالية تحفظ البيانات في localStorage على الجهاز الحالي فقط، وليست آمنة أو مشتركة بين الزوار. قبل النشر الرسمي يجب ربط قاعدة بيانات وتسجيل دخول آمن. تضمين منشور Telegram لا يضمن استخراج الملف كصوت/فيديو مستقل. روابط الصوت والفيديو المباشرة تحتاج أن يسمح المصدر بالتشغيل عبر المتصفح. استخدم المحتوى والصور بإذن مناسب.
